# Sniffer and RA Monitor Implementation Plan (Plan 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the passive ND/RA sniffer to the collector. It covers hosts that can't run the agent by recording MAC↔address sightings (`nd.*`) and router advertisements (`ra.*`). It also adds the `hosts` view, sighting-aware `collector query`, and MAC lookup from sightings for registrations (`mac_src = "nd"`).

**Architecture:**
- **Capture and parsing.** A Linux `AF_PACKET` socket per `sniff` interface has a kernel BPF filter (ICMPv6 133–136) and `PACKET_AUXDATA` for VLAN tags. Frames are parsed by a pure, fuzzed codec, `internal/nd`.
- **State.** Two pure, clock-driven state machines in `internal/collector/sniffer` turn packets into sightings and router records. `Tracker` collapses, expires, detects conflicts and flags proxies. `RAMonitor` detects new and changed routers.
- **Storage and delivery.** Both write through the existing `recorder.Recorder` into new `sightings` and `routers` tables. Syslog delivery is unchanged: the forwarder already ships whatever lands in `events`.

**Tech Stack:** Go 1.26, `golang.org/x/sys/unix` (AF_PACKET, auxdata), `golang.org/x/net/bpf`, `modernc.org/sqlite`, the existing collector packages.

**Spec:** `docs/superpowers/specs/2026-11-08-ipv6-slaac-logger-design.md` (§3.1–3.3, §5.5, §5.6, §5.7 severity, §6, §7). Plan 1 (`docs/superpowers/plans/2026-11-08-collector-core.md`) is implemented. This plan modifies its packages.

**Independent of Plan 2 (agent).** The only shared file is `test/e2e/e2e_linux_test.go` plus the `radvd` install step in `ci.yml`. Whichever plan lands second reuses `startRadvd` and the install step instead of adding them again.

## Global Constraints

- Module path `github.com/buraglio/ipv6-slaac-logger`. Pure Go, `CGO_ENABLED=0`, no libpcap.
- The capture code is `//go:build linux`. `internal/nd`, `Tracker`, `RAMonitor`, the BPF program, the store and the query code are portable and pass tests on linux, darwin and windows. `cmd/collector` stays `!windows`.
- Event types (already in `internal/event`): `nd.new`, `nd.expire`, `nd.conflict`, `ra.seen`, `ra.change`. Severity is unchanged (info: `nd.new` and `ra.seen`; notice: `nd.conflict`, `nd.expire` and `ra.change`).
- Sniffer events carry `mac`, `addr`, `link` (interface name), `vlan` (omitted when untagged) and `kind` (`dad`, `ns`, `na`, `rs`). RA events carry the router MAC in `mac`, the router link-local address in `addr`, `link`, `vlan`, the M/O flags, `prefixes` and `router_lft`.
- Defaults: idle expiry **24h**; database write of a repeat sighting **at most every 5 min per key**; `log_link_local = false`; proxy threshold **32** addresses per MAC per link.
- Refreshes and repeat sightings update `last_seen` only and never produce syslog lines.
- No panic on any frame. Every parser checks lengths and offsets and is fuzzed.
- GitHub Actions pinned exactly as in the existing `ci.yml`.

## Spec interpretation notes (decided while planning)

- **No `mdlayher/packet`.** On Linux, AF_PACKET delivers frames with the 802.1Q tag already stripped into socket metadata on virtually every driver (hardware VLAN offload, and always on veth). Reading it requires `PACKET_AUXDATA` control messages, which `mdlayher/packet` doesn't expose. The capture socket is therefore opened directly with `x/sys/unix`: `socket(AF_PACKET, SOCK_RAW, ETH_P_ALL)`, bind to the ifindex, `SO_ATTACH_FILTER`, `PACKET_AUXDATA`, `PACKET_ADD_MEMBERSHIP` with `PACKET_MR_PROMISC`, and `Recvmsg`. This is still pure Go. In-frame tags (QinQ inner tag, or no offload) are parsed too.
- **Outgoing frames are kept,** so a collector that is also the router sees its own RAs.
- **Promiscuous mode is always on** for sniff interfaces. Without it the NIC drops solicited-node multicast and SPAN traffic.
- **Store batching (deferred from Plan 1).** The tracker batches repeat-sighting writes itself: one `Change` per flush tick holds every due sighting. With `SetMaxOpenConns(1)`, SQLite already has a single writer. No separate writer goroutine is added.
- **`sightings` keeps rows after expiry** (`expired = 1`) until `last_seen` is older than `retention_days`. If a sighting reappears after expiry, the row is reused, `first_seen` resets, and a new `nd.new` is emitted. Earlier windows remain in `events` (`nd.new`/`nd.expire` carry `first_seen`/`last_seen`).
- **`nd.conflict`** means a new MAC for an (addr, link, vlan) that has a different non-expired MAC. It is emitted instead of `nd.new` and carries `prev_mac`. The previous sighting is not expired by it: both MACs may genuinely answer, which is exactly what an operator needs to see.
- **Proxy suspects.** When a MAC holds more than 32 non-expired addresses on one link and VLAN, all its sightings get `proxy_suspect = 1`, one Warn process-log line is written, and from then on that MAC produces no `nd.*` events. Sightings are still stored. The `hosts` view and the registrar's MAC lookup ignore proxy-suspect rows.
- **Flood bounds.** At most `max_entries` (default 100000) live keys are kept; beyond that new keys are dropped and counted in `sniff_overflow`. `nd.new` and `nd.conflict` events share a token bucket (20/s, burst 200); beyond it, the sighting is stored but no event is written, counted in `nd_suppressed`. Both counters appear in the 15-minute `stats` event.
- **`ra.seen` and `ra.change`.** Routers are keyed by (link, vlan, router MAC, router link-local). The first RA from a key gives `ra.seen`. A later RA whose M flag, O flag or sorted prefix set differs gives `ra.change`. A change in router lifetime alone is stored but not logged. RAs from a non-link-local source are dropped and counted as `nd_invalid` (RFC 4861 §6.1.2).
- **ND validity (RFC 4861 §6.1):** hop limit 255, ICMPv6 code 0, a valid checksum, the minimum lengths, and no zero-length options. NS/NA targets must not be multicast. A DAD NS (`::` source) must have a solicited-node destination. Failures are counted in `nd_invalid`, never logged per packet.
- **Registrar MAC precedence** becomes cllao (4) > vendor (3) > **nd (2)** > duid (1). An observed wire mapping beats the MAC embedded in a DUID, which often belongs to another interface. The `l2` source in spec §3.2 remains unimplemented: the UDP listener can't see Ethernet source addresses.
- **Event JSON names** for the new fields: `vlan`, `kind`, `prev_mac`, `managed`, `other`, `prefixes`, `router_lft`.

## Review Focus

1. **A flood of spoofed DAD NS with random MACs and addresses** (a trivial attack on any LAN): memory stays bounded at `max_entries`, syslog volume stays bounded by the event bucket, and the collector keeps registering. Tests: `TestTrackerBoundsEntries`, `TestTrackerBoundsEventRate` (Task 4).
2. **A router doing proxy ND, or a firewall answering NS for a whole subnet:** after the threshold, no per-address `nd.*` events, no misleading `hosts` rows, and the registrar never uses that MAC. Tests: `TestTrackerProxySuspect` (Task 4), `TestHostsViewIgnoresProxySuspects` (Task 3).
3. **A collector restart:** no burst of `nd.new`/`ra.seen` for hosts and routers already known, because state is warm-loaded from the database. Tests: `TestTrackerWarmStartNoDuplicateNew` (Task 4), `TestRAMonitorWarmStart` (Task 5).
4. **Malformed, truncated or hostile frames** (bad option lengths, wrong hop limit, bad checksum, deep VLAN stacks): dropped and counted, never a panic. Tests: `FuzzParse` and `TestParseRejects` (Task 1), `TestFilterProgram` (Task 2).
5. **A sniff interface that is missing at startup or disappears** (USB NIC, SPAN reconfigured): the collector keeps running, logs once, and retries with backoff. It doesn't exit, and other interfaces are unaffected. Test: `TestRunSniffersRetriesMissingInterface` (Task 7).

```go
const ( TypeRS uint8 = 133; TypeRA uint8 = 134; TypeNS uint8 = 135; TypeNA uint8 = 136 )
type Prefix struct { Prefix netip.Prefix; OnLink, Autonomous bool; Valid, Preferred uint32 }
type RA struct { Managed, Other bool; RouterLifetime uint16; Prefixes []Prefix }
type Packet struct {
	SrcMAC, DstMAC net.HardwareAddr
	VLAN           uint16 // 0 = untagged
	Src, Dst       netip.Addr
	Type           uint8
	Target         netip.Addr       // NS/NA only
	LLAddr         net.HardwareAddr // SLLA (RS/RA/NS) or TLLA (NA); nil when absent
	NAFlags        uint8            // R=0x80 S=0x40 O=0x20 (NA only)
	RA             *RA              // RA only
}
var ( ErrNotND = errors.New("nd: not a neighbor discovery packet")
      ErrMalformed = errors.New("nd: malformed") )
// Parse decodes an Ethernet frame. auxVLAN is the tag from PACKET_AUXDATA (0 if none);
// when nonzero it wins over an in-frame tag.
func Parse(frame []byte, auxVLAN uint16) (Packet, error)
func IsSolicitedNode(a netip.Addr) bool // ff02::1:ffXX:XXXX
```

Parse rules:
- Ethernet: at least 14 bytes. Skip up to 2 tags of type `0x8100` or `0x88a8`. `VLAN` is `auxVLAN` if nonzero, else the first in-frame tag's `TCI & 0x0fff`. A third tag or a non-`0x86dd` ethertype → `ErrNotND`.
- IPv6: version 6, and `payload length` must fit the remaining bytes (trailing Ethernet padding is allowed and ignored). Next header ≠ 58 → `ErrNotND`. Hop limit ≠ 255 → `ErrMalformed`.
- ICMPv6: the type must be 133–136, else `ErrNotND`. The code must be 0. The checksum must verify over the IPv6 pseudo-header. Minimum body lengths: RS 8, RA 16, NS 24, NA 24.
- Options: an 8-byte-unit length of 0, or an option overrunning the payload → `ErrMalformed`. SLLA (1) and TLLA (2) with length 1 → 6-byte MAC. Prefix Information (3) must have length 4, and its prefix is masked to the prefix length. Other options are skipped.
- NS/NA with a multicast target → `ErrMalformed`. An NS from `::` that isn't to a solicited-node address → `ErrMalformed`. An NS from `::` with an SLLA option → `ErrMalformed` (RFC 4861 §7.1.1).

```sql
CREATE TABLE IF NOT EXISTS sightings (
  mac TEXT NOT NULL, addr TEXT NOT NULL, link TEXT NOT NULL, vlan INTEGER NOT NULL DEFAULT 0,
  kind TEXT NOT NULL, first_seen INTEGER NOT NULL, last_seen INTEGER NOT NULL,
  proxy_suspect INTEGER NOT NULL DEFAULT 0, expired INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (mac, addr, link, vlan));
CREATE INDEX IF NOT EXISTS sightings_addr ON sightings(addr);
CREATE INDEX IF NOT EXISTS sightings_last ON sightings(last_seen);
CREATE TABLE IF NOT EXISTS routers (
  link TEXT NOT NULL, vlan INTEGER NOT NULL DEFAULT 0, mac TEXT NOT NULL, addr TEXT NOT NULL,
  managed INTEGER NOT NULL, other INTEGER NOT NULL, prefixes TEXT NOT NULL, lifetime INTEGER NOT NULL,
  first_seen INTEGER NOT NULL, last_seen INTEGER NOT NULL,
  PRIMARY KEY (link, vlan, mac, addr));
CREATE VIEW IF NOT EXISTS hosts AS
  SELECT b.addr, b.duid, b.host, CASE WHEN b.mac <> '' THEN b.mac ELSE COALESCE(s.mac, '') END AS mac,
         CASE WHEN b.mac <> '' THEN b.mac_src WHEN s.mac IS NOT NULL THEN 'nd' ELSE '' END AS mac_src,
         COALESCE(s.link, b.link) AS link, COALESCE(s.vlan, 0) AS vlan,
         MIN(b.first_seen, COALESCE(s.first_seen, b.first_seen)) AS first_seen,
         MAX(b.last_seen, COALESCE(s.last_seen, b.last_seen)) AS last_seen
  FROM bindings b LEFT JOIN sightings s
    ON s.addr = b.addr AND s.proxy_suspect = 0 AND s.expired = 0 AND (b.mac = '' OR s.mac = b.mac)
  UNION ALL
  SELECT s.addr, '', '', s.mac, 'nd', s.link, s.vlan, s.first_seen, s.last_seen
  FROM sightings s
  WHERE s.proxy_suspect = 0 AND s.expired = 0 AND NOT EXISTS (SELECT 1 FROM bindings b WHERE b.addr = s.addr);
```

**Interfaces:**
- Consumes: `Observation` (Task 2); `store.Sighting`, `store.Change` (Task 3); `event.*`; the `registrar.Recorder` interface shape (`Record(ctx, store.Change) error`), redeclared locally as `Recorder`
- Produces:

```go
type TrackerConfig struct {
	Idle           time.Duration // 24h
	Flush          time.Duration // 5m
	LogLinkLocal   bool          // false
	ProxyThreshold int           // 32
	MaxEntries     int           // 100000
	EventRate      float64       // 20 per second
	EventBurst     int           // 200
}
func DefaultTrackerConfig() TrackerConfig
type Tracker struct { /* mutex-protected; safe for concurrent Observe from several interfaces */ }
func NewTracker(cfg TrackerConfig, rec Recorder, now func() time.Time, log *slog.Logger) *Tracker
func (t *Tracker) Load(rows []store.Sighting)            // warm start: non-expired rows, no events
func (t *Tracker) Observe(ctx context.Context, o Observation)
func (t *Tracker) Tick(ctx context.Context)              // expire idle keys; flush dirty keys due
func (t *Tracker) MACFor(addr netip.Addr) (string, bool) // most recently seen, non-proxy, non-expired
func (t *Tracker) Counters() map[string]uint64           // sniff_overflow, nd_suppressed, nd_sightings
```

Behaviour:
- Key = (MAC, addr, link, vlan).
- **Known key:** update `LastSeen` and `Kind` and mark it dirty. No write and no event.
- **New key:**
  - If there are `MaxEntries` live keys, drop it and increment `sniff_overflow`.
  - Otherwise, if a live key has the same (addr, link, vlan) with a different MAC, and neither MAC is proxy-suspect, the event is `nd.conflict` with `prev_mac`. Otherwise the event is `nd.new`.
  - The event is suppressed (row only) when the address is link-local and `!LogLinkLocal`, when the MAC is proxy-suspect, or when the token bucket is empty (`nd_suppressed++`).
  - Record immediately: one `Change` with the sighting (and the event, if any).
- **Proxy check** after each new key: count live keys for (MAC, link, vlan). When the count exceeds `ProxyThreshold` for the first time, mark every such key `ProxySuspect` and dirty, and log Warn `proxy_suspect` once with mac and link.
- **Tick:**
  - Every key with `now − LastSeen ≥ Idle` gets `nd.expire` (same suppression rules, except the token bucket: expiries are never rate-limited) with `first_seen`/`last_seen`. Its row is written `Expired=true` and the key is removed from memory.
  - Every dirty key whose last write was at least `Flush` ago is written.
  - Everything from one Tick goes in a single `Change`.
- **Recorder errors:** log them and keep the in-memory state. Dirty keys stay dirty for the next Tick.
- **Event fields:** `mac`, `addr`, `link`, `vlan`, `kind`, and for `nd.expire` also `first_seen`/`last_seen`. `origin` is `"sniffer"` and `via` is `"sniff"`.

- Produces:

```go
type FrameSource interface {
	// ReadFrame fills buf and returns the frame length and aux VLAN (0 if none).
	// It returns os.ErrDeadlineExceeded every ~1s when idle, so callers can observe ctx.
	ReadFrame(buf []byte) (n int, vlan uint16, err error)
	Close() error
}
func Open(ifname string) (FrameSource, error) // linux: AF_PACKET; other: errors.ErrUnsupported
func parseAuxVLAN(oob []byte) uint16          // linux only; 0 unless TP_STATUS_VLAN_VALID

type Sniffer struct {
	Link    string
	Open    func(string) (FrameSource, error) // default Open
	Tracker *Tracker
	RA      *RAMonitor
	Log     *slog.Logger
	// counters (atomic): frames, nd_malformed, nd_not_nd
}
func (s *Sniffer) Run(ctx context.Context) // opens with backoff (logger.Backoff, max 60s), reads, dispatches; never returns early except on ctx
func (s *Sniffer) Counters() map[string]uint64
```

Linux capture details:
1. `unix.Socket(AF_PACKET, SOCK_RAW|SOCK_CLOEXEC, htons(ETH_P_ALL))`.
2. `SetsockoptSockFprog(SOL_SOCKET, SO_ATTACH_FILTER, …)` with `Filter()`. Attach it **before** `bind`, so no unfiltered frames are queued.
3. `Bind(&SockaddrLinklayer{Protocol: htons(ETH_P_ALL), Ifindex})`.
4. `SetsockoptInt(SOL_PACKET, PACKET_AUXDATA, 1)`.
5. `SetsockoptPacketMreq(SOL_PACKET, PACKET_ADD_MEMBERSHIP, &PacketMreq{Ifindex, Type: PACKET_MR_PROMISC})`.
6. `SO_RCVTIMEO` 1 s.

`ReadFrame` uses `unix.Recvmsg` with a 64-byte OOB buffer. `parseAuxVLAN` walks `unix.ParseSocketControlMessage` for `SOL_PACKET`/`PACKET_AUXDATA` and reads `unix.TpacketAuxdata` (`Status & TP_STATUS_VLAN_VALID`, `Vlan_tci & 0x0fff`). `EAGAIN` → `os.ErrDeadlineExceeded`.
